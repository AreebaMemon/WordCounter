# WordCounter

A simple yet powerful WordCounter that helps you count words, characters, vowels, and convert case formats with ease.

## Features

* **Word Count:** Tracks the number of words in your text.
* **Character Count:** Measures the total number of characters.
* **Vowel Count:** Calculates the total number of vowels (A, E, I, O, U,a,e,i,o,u).
* **Case Conversion:** Easily switch between lowercase, uppercase formats.
